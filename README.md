# NICE — Premium Perfume Landing Page

A fully responsive, animation-heavy perfume landing page built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — page structure/content
- `style.css` — complete responsive styling and animations
- `script.js` — cursor, magnetic buttons, 3D tilt, reveal animations, parallax and mobile navigation
- `assets/nice-perfume-enhanced.png` — enhanced version of the supplied product image

## Run

Simply open `index.html` in a modern browser.

For the best experience, use a local server such as VS Code Live Server.

## Included effects

- Premium dark editorial visual direction
- Responsive desktop/tablet/mobile layout
- Custom cursor with interactive hover state
- Magnetic buttons
- 3D product tilt
- Product shine sweep
- Rotating decorative rings
- Scroll reveal animations
- Lightweight scroll parallax
- Infinite typography marquee
- Responsive mobile menu
- Smooth hover transitions
- Accessibility-friendly image alt text and semantic sections

## Customize

Search `NICE`, `$49`, and the copy in `index.html` to replace the demo content with your actual product details, price, CTA and brand information.
